## Findings

No CONFIRMED or HIGH CONFIDENCE vulnerabilities. No code changes were made.

| ID | Class | Sev | CWE | Location | Note |
|---|---|---|---|---|---|
| N-01 | POSSIBLE | Low | CWE-200 | `src/Webhooks/PayloadFormatter.php:66-72` | The plain `json` format sends `data` as given, whereas `form` and `template` run it through `redact()` (secret-looking keys masked). Core's `AuditService` already redacts before `afterLog` (SR-06), so exposure needs an edition that emits events carrying secret keys outside that path. Consider applying `redact()` to `json` in 2.0 (it would change the wire format, so not done here). |
| N-02 | FALSE POSITIVE | n/a | CWE-918 | `UrlPolicy::vet`, `WebhookDispatcher::curlTransport` | Tried to bypass the SSRF guard through trailing-dot hosts, userinfo, `{txn}` substitution and proxies. Verified: the vetted host is the one curl is pinned to (`pinnedUrl`, `CURLOPT_RESOLVE`), userinfo is rejected, `{txn}` is a hex hash, proxies are disabled when pinned, redirects are off, protocols are limited. Resolution is repeated on every attempt. The policy remains opt-in (known, SR-15). |
| N-03 | FALSE POSITIVE | n/a | CWE-1336 | `PayloadTemplate` | Template injection and escaping break-out: substitution is single-pass, values are never re-parsed, output is escaped per encoding, `|json` must be last, and size and placeholder limits apply. |
| N-04 | FALSE POSITIVE | n/a | CWE-113 | `Authentication`, `WebhookDispatcher::mergeExtraHeaders` | Header injection: names are RFC 7230 tokens (`\z`/D), values reject control characters, framing and signature headers are forbidden, and the formatter's own headers (ntfy Click, Title) pass through the same validation. |
| N-05 | FALSE POSITIVE | n/a | CWE-78 | `src/Cron/JobRunner.php:156` | `exec()` of a shell string: every component goes through `escapeshellarg`, the script must resolve under `cron/` or `scripts/`, the PHP binary is allow-listed and arguments are matched against a strict regex. |

Sweep results: no `unserialize`, `eval`, `md5`/`sha1`/`rand`-based secrets or disabled TLS verification in `src/`;
`proc_open` in `KB/PdfConverter` uses an argv array (no shell).
