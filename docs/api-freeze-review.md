# Public API freeze review (issue #30)

Status at 0.17.0. The public surface is every class tagged `@api` (82 types); the full signature list is
[api-surface.md](api-surface.md), regenerated by `php scripts/api-surface.php`. Everything tagged `@internal`
(migration classes, the test case base class, small helpers) is outside the semver promise.

## What is settled

- **Contracts** (`Database`, `Contracts`, `Redis\RedisClientProviderInterface`, `Webhooks\*Interface`, `ITSM\TicketProblemLinkInterface`,
  `Mcp\AgentDirectoryInterface`, `Compliance\*Interface`): small, edition-implemented, already used by two editions. Frozen as is.
- **Errors:** modules throw `DatabaseException` for storage failures, their own exception for refusals
  (`PdfConversionException`, `DocxConversionException`, `PermanentJobFailure`, `AccessDenied`), and fail open (return
  "not acquired"/allow) where Redis is involved.
- **Tables and columns:** only additive migrations (0001 to 0012), each idempotent and recorded in `rivet_core_migrations`.

## To resolve before 1.0.0

1. **Long positional constructors.** `RedisConnectionConfig` (10 params), `WebhookDispatcher` (8), `ToolPipeline` (7) grew by
   appending optional arguments. Decide per class: keep (named arguments are the supported way to call them) or move
   options into a value object. Recommendation: document "call with named arguments" and freeze, except `WebhookDispatcher`,
   which gets an options object in 0.18.
2. **Untyped array shapes.** 69 public methods return or take plain `array`; PHPStan ignores the missing-generics rule
   (`missingType.iterableValue`). Before 1.0 annotate each with `array<...>` shapes so editions get completion and the BC
   checker can see shape changes.
3. **`@internal` test helper.** `Testing\DatabaseContractTestCase` extends PHPUnit and is used by both editions' suites.
   Decision #49 (separate dev package or keep) must land before 1.0 because it is outside the BC promise today.
4. **Logger.** Services that logged to `error_log()` now take a PSR-3 logger (closures still accepted for the three MCP
   classes); `ErrorLogLogger` is the default. Freeze the `\Closure|LoggerInterface|null` union or drop the closure at 1.0
   (recommendation: drop it, editions pass a logger).
5. **Access policy.** `AccessPolicyInterface` (ADR-003) ships but no service enforces it yet. First adopters: Automation
   execution and MCP tool calls; freeze after one real adopter in each edition.
6. **Webhook v2 signature.** `X-Rivet-Signature-V2` is new and additive; retries need `$signedAt` per attempt for the replay
   window to mean anything. Decision #47 (when to retire the legacy header) is open.
7. **Namespaces.** The edition shims under `ITFlow\` stay for 1.x (decision #45 recommended: yes, deprecated, not removed).
