# Shared design assets

Core-owned CSS/JS for every Rivet edition. Do not edit the files in an edition; change them here and regenerate the manifest
(`php scripts/build-ui-manifest.php`). Install into an edition with `scripts/install-ui-assets.php`, verify with
`scripts/check-ui-assets.php`. Load order, token contract and the per-file ownership table: `docs/ui/DESIGN_ASSETS.md`
(in the Git repository; documentation is not part of the Composer package).
